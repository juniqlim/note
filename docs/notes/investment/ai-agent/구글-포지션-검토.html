  • AWS 29% (하락 추세) / Azure 20% (상승) / GCP 13% (소폭 상승)

  • Gemini 3 Pro: LMArena 텍스트 벤치마크 1위 (Elo 1500 돌파)

AI 검색 침투

  • 구글 검색 점유율 90% 아래로 하락 (2025년)
  • AI 검색(Perplexity 등) 12~15% 점유
  • Perplexity: 월 7.8억 쿼리, 4,500만 활성 유저
  • 핵심 리스크: 구글이 자체 AI Overviews로 고마진 검색 매출을 자기잠식할 가능성
